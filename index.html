Higher or Lower — README

Overview

Higher Lower is a browser-based dice game where the player competes against the computer. Both sides roll two dice, and the player must predict whether their total will be higher or lower. Correct guesses reward credits, while wrong guesses reduce the player’s score.

Features
  • Player vs computer dice gameplay
  • Higher or lower prediction system
  • Dynamic credit / score tracking
  • Gambling mechanic with adjustable credit value
  • Random dice generation with visual Unicode dice
  • Real-time win/lose feedback messages
  • Player name input system
Tech Stack
  • HTML5
  • CSS3
  • JavaScript (Vanilla ES6)
What I Learned
  • DOM manipulation and event handling
  • Game state management
  • Random number generation for game logic
  • Updating UI dynamically based on player actions
  • Structuring a complete browser game loop
Future Improvements
  • Better UI/UX redesign (modern game styling)
  • Animations for dice rolling
  • Sound effects for win/lose actions
  • High score system using local storage
  • Improved game balance and reset options
